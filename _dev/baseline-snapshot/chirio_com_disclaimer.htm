Cookies

I cookie sono file di testo di piccole dimensioni che vengono memorizzati sul disco rigido degli utenti di un server Web durante la navigazione. I cookie vengono assegnati agli utenti singolarmente e possono essere letti esclusivamente dal server Web che li ha emessi. Non è possibile utilizzare i cookie per infettare con dei virus il computer o eseguire programmi.
Un cookie può essere utilizzato per personalizzare l'accesso di un utente a una pagina Web e contiene in genere un identificativo univoco che consente al sito Web di tenere traccia dei singoli visitatori. Il tipo d’informazioni memorizzate, la divulgazione e la modalità del loro utilizzo vengono determinate dal server Web che ha creato il cookie.

Alcune aree del sito web www.chirio.com  usano o potrebbero usare la tecnologia "cookie" per migliorare le possibilità di utilizzo dei servizi offerti, associando un cookie al visitatore connesso. I cookies sono usati anche per determinare i valori di traffico del nostro sito.  I visitatori del sito potranno disabilitare nel proprio browser la funzionalità di accettazione dei cookies, ma in alcuni casi questo potrà comportare malfunzionamenti nell'uso del nostro sito. Tutte le informazioni contenute nei cookie utilizzati possono essere facilmente verificate aprendo il file del cookie da un qualsiasi editor di testi. La posizione del file all’interno del disco dell’utente, dipende dal browser internet utilizzato. Consigliamo pertanto di consultare la guida in linea del proprio browser al fine di controllare i parametri impostati sul Vostro computer.
